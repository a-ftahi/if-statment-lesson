What is a Variable?

A named storage box in computer memory

A variable is a named location in a computer's memory that can store one item of data. Storing data in a variable is called assignment (using = in Python or ← in pseudocode).

Naming Rules: One word without spaces, cannot start with a number, and cannot be a reserved Python keyword (like if, print, input).

Getting User Input

Communicating with the outside world

Input is data the user enters into the program. In Python, we use the input() function.

⚠️ Crucial Rule for IF Statements:

By default, input() always returns a String (text)! If you want to compare numbers (like age or marks), you must cast it to an int():

Text string: name = input("Enter name: ")

Understanding Conditional Selection (IF, ELIF & ELSE)

Every day, you make decisions based on conditions. Computers do exactly the same thing using Selection! In programming, selection comes in three powerful forms: One-Way Selection (Single IF), Two-Way Selection (IF / ELSE), and Multi-Way Selection (IF / ELIF / ELSE).

“

1-Way Selection: If someone has a gluten allergy, then provide a gluten-free meal.

2-Way Selection: If it is raining, then take an umbrella, ELSE wear sunglasses & sunscreen! ☀️

Multi-Way Selection (ELIF): If score >= 90 then Grade A, ELIF score >= 75 then Grade B, ELIF score >= 50 then Grade C, ELSE Grade F! 🌟

The Evolution of Selection: With a single IF, there is no alternative plan (if False, code is skipped). With IF / ELSE, we have one guaranteed fallback. With IF / ELIF / ELSE, we can test multiple conditions sequentially — Python executes the first matching condition and skips all remaining branches!

🌟

Core Selection Concepts: 1-Way vs 2-Way vs Multi-Way

1. One-Way Selection (Pure IF) Single Branch

Executes a special block only when the condition is True. There is NO fallback!

✅ Condition is TRUE

Statements inside the IF block run immediately.

⏭️ Condition is FALSE

Inner code is skipped completely. Execution continues below.

2. Two-Way Selection (IF / ELSE) Dual Branch

Offers two distinct pathways: one for True and another guaranteed path for False.

✅ Condition is TRUE

The IF block statements run. The ELSE block is skipped.

🔄 Condition is FALSE

The ELSE block statements run! (Guaranteed fallback).

3. Multi-Way Selection (IF / ELIF / ELSE) Multi Branch

Tests multiple conditions in order. Executes the first True branch found, then skips all remaining branches!

⚡ First TRUE Match

Its specific block runs immediately. All remaining ELIF & ELSE blocks are skipped!

🛡️ All FALSE Fallback

If zero conditions match, the optional ELSE block catches everything!

Conditions & Comparison Operators

A condition is a comparison test that can result in only one of two Boolean values: True or False.

Operator Description Python Syntax Example Evaluation
== Equal to (checks if both sides match) == (Two equal signs!) 10 == 10 True
!= Not equal to != 5 != 2 True
> Greater than > 20 > 19 True
< Less than < 1 < 2 True
>= Greater than or equal to >= 50 >= 50 True
<= Less than or equal to <= 82 <= 99 True
🚨

Top Mistake: = vs ==

A single equals sign = is for ASSIGNMENT (storing a value in a variable): score = 100.
A double equals sign == is for COMPARISON (asking "Are these two equal?"): score == 100.

IF / THEN, IF / ELSE & ELSE IF in Pseudocode

In pseudocode, selection statements tell us where the decision begins, which condition is tested, what statements run when True, how additional alternative conditions are checked (ELSE IF), what statements run when all conditions fail (ELSE), and where the decision concludes (ENDIF).

Format 1: One-Way

Pure IF / THEN Format

IF condition THEN
statements when True
ENDIF
  • IF & THEN: Begins the selection statement and specifies the condition test.
  • Indentation: The statements inside are indented so we know they belong to the IF.
  • No ELSE: If condition is False, inner code is skipped completely.
  • ENDIF: Marks where the IF statement ends!
Format 2: Two-Way

IF / THEN / ELSE Format

IF condition THEN
statements when True
ELSE
statements when False
ENDIF
  • ELSE: Executes when the condition is False. Notice: No condition is written after ELSE!
  • Dual Indentation: Both the True statements and the False statements are indented.
  • Mutual Exclusion: Exactly ONE block executes, never both!
  • ENDIF: Both branches merge and continue here.
Format 3: Multi-Way

IF / THEN / ELSE IF / ELSE

IF condition1 THEN
statements 1
ELSE IF condition2 THEN
statements 2
ELSE
statements if all False
ENDIF
  • ELSE IF: Tests a new condition only if the previous conditions were False.
  • Unlimited Chains: You can chain as many ELSE IF branches as you need.
  • First Match Wins: As soon as one condition evaluates to True, Python runs its block and skips the rest.
  • ENDIF: Concludes the entire multi-way structure.

IF / ELSE: Exam Pass or Fail Decision

Asks for a student's score. Outputs Pass if ≥ 50, otherwise outputs Fail:

algorithm_pass_fail.pc 
OUTPUT "Enter student mark"
mark = INPUT
IF mark >= 50 THEN
    OUTPUT "Status: PASS! 🎉"
ELSE
    OUTPUT "Status: FAIL. Retake! 📚"
ENDIF
OUTPUT "Grading complete"

Trace input 75: 75 ≥ 50 is True → Outputs "Status: PASS! 🎉" → Outputs "Grading complete".

Trace input 42: 42 ≥ 50 is False → Runs ELSE → Outputs "Status: FAIL. Retake! 📚" → Outputs "Grading complete".

IF / ELSE IF / ELSE: Letter Grades

Asks for student marks (0-100). Assigns Grade A, B, C or F:

Trace input 80: 80 ≥ 90 is False → 80 ≥ 75 is True → Outputs "Grade: B" → Skips rest!

Trace input 35: None match → Runs ELSE → Outputs "Grade: F".

Translating IF, ELIF & ELSE into Python

Moving from pseudocode to real Python code is easy once you understand Python's exact syntax rules for single if, dual-branch if / else, and multi-branch if / elif / else structures!

📝

Pseudocode Feature

Keyword (Single IF): IF ... THEN
Keyword (Multi-Way): ELSE IF ... THEN
Keyword (Alternative): ELSE
Equality Check: = or ==
How to mark end: ENDIF keyword
Input string: INPUT name
Input number: INPUT score
→
Translates To
🐍

Python Syntax Rule

Keyword (Single IF): if condition: (lowercase + colon!)
Keyword (Multi-Way): elif condition: ('else if', condition + colon!)
Keyword (Alternative): else: (lowercase + colon, NO condition!)
Equality Check: == (Must be double equals!)
How to mark end: Indentation! (No ENDIF, un-indent to finish)
Input string: name = input("Enter name: ")
Input number: score = int(input("Enter score: "))
:

1. The Colon (:) is Mandatory

At the end of your if condition:, elif condition:, and else: lines, you must include a colon. The colon signals Python that an indented code block follows!

→|

2. Indentation Defines Blocks

Python has no ENDIF. Instead, any line indented by 4 spaces (or 1 Tab) belongs inside that specific block. Once code returns to the left margin, it runs unconditionally!

⛔

3. The Golden Rule of else:

An else: statement NEVER takes a condition! Writing else score < 50: is an immediate syntax error. else: automatically catches every False case!

⚡

4. The Golden Rule of elif:

elif stands for "ELSE IF". Unlike else:, elif MUST have a condition! Python evaluates them sequentially from top to bottom. As soon as one matches, its block runs and all others are skipped!
